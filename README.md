## 🧠 專案簡介（Overview）
這是一個可互動的 **學期 GPA 成績計算工具網站**，  
可即時計算課程平均成績、顯示動態顏色變化、增刪課程項目，並提供成績排序功能。  

此專案主要用來練習 **DOM 操作、事件監聽、動畫效果與演算法應用**，  
同時兼具前端互動與介面設計美感。

---

## ⚙️ 使用技術（Tech Stack）
- **HTML5 / SCSS / CSS3**：響應式頁面與動態樣式  
- **Vanilla JavaScript (ES6)**：DOM 操作與互動邏輯  
- **GSAP (TimelineMax / TweenMax)**：開場動畫與過場效果  
- **Font Awesome**：按鈕圖示  
- **GitHub Pages**：靜態網站部署  

---

## 🌟 功能特色（Features）
- 🧮 **即時計算 GPA：**  
  輸入課程名稱、學分與成績，立即更新 GPA 顯示。  

- 🎨 **動態顏色回饋：**  
  根據成績區間（A、B、C、D、F）自動變換背景顏色。

- ➕ **新增／刪除課程項目：**  
  點擊「＋」可新增表單列，點擊垃圾桶按鈕可刪除項目（附動畫）。

- 🔃 **成績排序：**  
  提供「升序」與「降序」排序，使用自寫的 **Merge Sort** 實現。

- 🎬 **開場動畫效果：**  
  利用 GSAP 製作 hero 圖片展開與漸淡出轉場。
